# batdongsan-jp

Phiên bản tiếng Nhật của hệ thống Ancu365 — nền tảng bất động sản cho thị trường Nhật Bản.

## Cấu trúc

- `app/` — Flutter frontend (từ nhánh `jp-version` của ancu365-app)
- `backend/` — FastAPI + SQLAlchemy backend (từ nhánh `jp-version` của ancu365-backend)

Xem `app/CLAUDE.md` và `backend/CLAUDE.md` để biết cách build, chạy, deploy.
