# Tenant Welcome Email (Japanese)

**Subject:** Ancu365 へようこそ — あなたの賃貸情報が安全に管理されます

---

```
【件名】Ancu365 へようこそ — あなたの賃貸情報が安全に管理されます

[入居者名] 様

この度は、弊社経由でお部屋をお申し込みいただきありがとうございます。

あなたの応募情報は、Ancu365 という専用システムで安全に管理されています。
このメールでは、Ancu365 の使い方と、あなたのデータがどのように扱われるかについて、
簡潔にお知らせいたします。

【 Ancu365 とは？ 】

Ancu365 は、賃貸仲介業者様がお部屋の管理・入居者様の対応をするためのシステムです。
あなたは、以下の場面で Ancu365 を使うことになります：

✓ お部屋の申し込み情報の入力・確認
✓ 敷金や更新料の支払い確認
✓ 契約更新時の書類送付・返却
✓ その他、貴仲介業者からのお知らせ受け取り

【 あなたのデータについて 】

Q: 私の個人情報はどこに保管されるのですか？
A: 日本国内のセキュアなサーバーに暗号化された状態で保管されます。

Q: 誰がアクセスできるのですか？
A: あなたの情報は、担当の仲介業者のスタッフのみがアクセスできます。
   Ancu365 運営チームはアクセスできません（緊急対応時を除く）。

Q: どのくらい保管されるのですか？
A: 通常、お部屋の賃貸契約が終了してから 2 年間保管されます。
   その後、自動的に削除されます。

Q: データを削除してもらえますか？
A: はい。いつでも削除をリクエストできます。
   その場合、30 日間の確認期間後に自動削除されます。
   詳細: https://ancu365.jp/help/account-deletion

【 あなたの権利（APPI法対応）】

日本の個人情報保護法（APPI）により、あなたは以下の権利があります：

✓ 自分のデータを見る・ダウンロードする
  → https://ancu365.jp/app/dsr-export

✓ 間違っている情報を直す
  → support@ancu365.jp に連絡

✓ データの使用を止めてもらう
  → 設定画面から「データ利用の停止」を選択

✓ アカウントを削除する
  → 設定画面から「アカウント削除」を選択

【 セキュリティについて 】

✓ あなたの情報は暗号化されています
✓ Ancu365 へのログインには 2 段階認証が使えます
✓ ログインパスワードは複雑なものをお勧めします

【 よくある質問 】

Q: Ancu365 の利用は無料ですか？
A: あなたは無料です。利用料は仲介業者が支払います。

Q: Ancu365 を使いたくない場合は？
A: 仲介業者にお知らせください。別の方法で手続きします。

Q: データが漏れたらどうなるのですか？
A: 万が一の場合、Ancu365 チームが 72 時間以内に個人情報保護委員会に報告し、
   あなたにもお知らせします。

Q: 困ったことがあります。誰に連絡すればいい？
A: 以下までお問い合わせください：
   - 一般的な質問 → support@ancu365.jp
   - セキュリティ問題 → security@ancu365.jp
   - プライバシーについて → privacy@ancu365.jp

【 プライバシーポリシー 】

詳細な個人情報の取り扱いについては、以下をご参照ください：
https://ancu365.jp/privacy
```
