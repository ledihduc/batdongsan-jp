# 更新しない場合の手続き

契約更新のときに、お部屋を退出することにした場合の手続きについて説明します。

## 退出をお伝えするステップ

### 1. 早めに通知する
- 契約書に記載の「解約予告期間」を確認します
- 通常は退出希望日の 1～3 ヶ月前に通知が必要です
- 期限を過ぎると、余分な家賃が発生する場合があります

### 2. Ancu365 で連絡する
- 「連絡」タブから「退出希望」を選択
- 退出希望日を入力
- メッセージで理由があれば記入

### 3. 仲介業者から返答
- 仲介業者が受け取り、確認します
- 数日以内に返答が届きます

## 退出時の手続き

1. **原状回復（掃除・修繕）**
   - 引っ越し前にお部屋を片付けます
   - 大きな破損がないか、確認しましょう

2. **敷金精算**
   - クリーニング代や修繕費が差し引かれます
   - Ancu365 で詳しい計算を確認できます
   - 詳細は「敷金精算について」をご参照ください

3. **鍵の返却**
   - 仲介業者の指示に従い、鍵を返します
   - 返却日時を確認しましょう

4. **引っ越し完了**
   - 引っ越し後、住所変更の手続きをしてください

## 重要なポイント

- **解約予告期間を守る**
  → 守らないと、余分な家賃を請求される場合があります

- **敷金精算に疑問がある場合**
  → 仲介業者に質問します。明細書をしっかり確認してください

- **トラブルが発生した場合**
  → Ancu365 の「問い合わせ」から相談できます

ご不明な点は、いつでも仲介業者にお問い合わせください。
