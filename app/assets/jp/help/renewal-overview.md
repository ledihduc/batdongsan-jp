# 更新手続きについて

契約の更新時期が近づくと、Ancu365 からあなたにお知らせが届きます。

## 更新手続きの流れ

1. **通知を受け取る**
   - メール、または Ancu365 アプリでお知らせが届きます
   - 更新期日の 60 日前から連絡が始まります

2. **書類を確認する**
   - Ancu365 で新しい契約書の案を確認できます
   - 条件に変更がないか、見直しましょう

3. **署名・提出する**
   - 電子署名、または書類に署名して返送
   - 仲介業者の指示に従ってください

4. **契約完了**
   - 仲介業者が確認したら、契約更新は完了です
   - 新しい契約書が Ancu365 に保存されます

## よくある質問

**Q: 更新手続きにいくらかかりますか？**
A: 仲介業者によって異なります。Ancu365 では、更新に必要な費用内訳を確認できます。詳しくは「更新費用の内訳」を参照ください。

**Q: 更新を希望しない場合は？**
A: 仲介業者に直接お伝えください。Ancu365 の「連絡」機能で通知できます。

**Q: 契約書の内容に疑問があります**
A: 仲介業者に質問してください。不明な点は契約前に解決しましょう。
