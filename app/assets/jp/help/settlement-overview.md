# 敷金精算について

引っ越し退出後、敷金から修繕費やクリーニング代が差し引かれて、残額が返金されます。

## 敷金精算とは

- **敷金** = 入居時に大家さんに預けるお金（通常、家賃の 1～2 ヶ月分）
- **精算** = お部屋を退出するときに、使用状況に応じて計算し直すこと

## 精算の計算方法

### 敷金から差し引かれるもの

1. **クリーニング代**
   - お部屋全体の清掃費用
   - 通常、クロスや床の軽い汚れなら含まれます

2. **修繕費**
   - 破損・傷の修理代
   - 通常の使用範囲内の傷は、請求されません
   - 故意や過失による破損は、借主負担の場合があります

3. **その他費用**
   - 鍵交換代（規約で定めてある場合）
   - 害虫駆除（契約書に記載がある場合）

### Ancu365 での確認方法

1. アプリを開く
2. 「敷金精算」タブをタップ
3. 内訳が表示されます
   - 敷金の元額
   - 差し引かれる費用
   - 返金予定額
   - 支払い期限

## 精算までの流れ

1. **退出報告** → 仲介業者に退出予定を伝える
2. **立ち会い検査** → 大家さんまたは仲介業者がお部屋を確認
3. **見積書作成** → Ancu365 に費用の内訳が表示されます
4. **合意** → 内容に同意します
5. **返金** → 通常、1～2 ヶ月で指定口座に返金されます

## 返金がない場合

敷金精算で全額が修繕費に当てられた場合、返金はありません。これは法律で認められている場合があります。

## 精算に疑問がある場合

「敷金精算に異議がある」セクションを参照してください。
