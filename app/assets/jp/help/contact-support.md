# サポートに問い合わせる

Ancu365 についてご質問や困ったことがある場合、以下の方法でお問い合わせください。

## 問い合わせ方法

### 1. Ancu365 アプリ内の「問い合わせ」機能
- **最も便利です**
- Ancu365 を開く → 下部の「問い合わせ」をタップ
- あなたのアカウント情報が自動入力される
- 返答は 24～48 時間以内
- チャット形式で会話できる

### 2. メール
- **メールアドレス:** support@ancu365.jp
- **返答時間:** 24～48 時間以内
- 詳しい説明が必要な場合に便利
- 添付ファイル送信可能

### 3. 電話
- **電話番号:** 0XX-XXXX-XXXX
- **営業時間:** 平日 10:00–18:00 JST
- **土日祝日:** 休業
- 緊急の場合に便利
- 待ち時間がある場合があります

### 4. チャット（時間外対応）
- **URL:** https://ancu365.jp/app/support
- **対応時間:** 24 時間
- 自動返答（AI）と人間による回答が混在

## 問い合わせの際に用意すること

| 項目 | 説明 |
|---|---|
| あなたのメールアドレス | アカウント識別のため |
| 問題が発生した日時 | より正確な対応のため |
| 問題の詳しい説明 | スクリーンショットがあるとベター |
| エラーメッセージ | そのままコピー・ペーストしてください |
| 試したこと | 「●●をしましたが直りません」 |

## よくある質問の答え

### 問い合わせ前に、以下を確認してください

| 問題 | 対処法 |
|---|---|
| アプリが起動しない | デバイスを再起動、アプリをアップデート |
| ログインできない | パスワードをリセット、メール確認 |
| 通知が来ない | 通知設定を確認、アプリの権限設定を確認 |
| ページが表示されない | インターネット接続を確認、ブラウザキャッシュを削除 |
| 身分証がアップロードできない | ファイルサイズを確認、別の撮影法を試す |

## 問い合わせジャンル別ガイド

### 「登録・ログイン」について
- アカウント作成ができない
- パスワードをリセットしたい
- メールアドレスを変更したい

→ **推奨:** アプリの「問い合わせ」またはメール

### 「更新手続き」について
- 更新料の計算が合わない
- 書類の提出方法がわからない
- 期限を過ぎてしまった

→ **推奨:** 電話（急ぎの場合）または「問い合わせ」

### 「敷金精算」について
- 精算額が高い気がする
- 修繕費に異議がある
- 返金がまだ来ない

→ **推奨:** 「問い合わせ」で詳しく説明（相談員が仲介業者に確認します）

### 「支払い」について
- 支払い方法を変更したい
- 支払い期限を延ばしてほしい
- 支払い失敗の理由がわからない

→ **推奨:** 電話（支払いに関するため）

### 「プライバシー・セキュリティ」について
- データを削除したい
- データをダウンロードしたい
- セキュリティ問題を報告したい

→ **推奨:** 「問い合わせ」（個人情報のため）
→ **緊急:** security@ancu365.jp

### 「技術的な問題」について
- アプリが動作しない
- バグを報告したい
- 改善案を提案したい

→ **推奨:** チャット（技術チームが対応）

## 返答時間の目安

| 問い合わせ方法 | 返答時間 |
|---|---|
| アプリ内「問い合わせ」 | 24～48 時間 |
| メール | 24～48 時間 |
| 電話 | その場で対応 |
| チャット（24h） | 数分～数時間（時間帯による） |

## よくある質問（FAQ）

**Q: 夜間に問い合わせしたい場合は？**
A: チャット（https://ancu365.jp/app/support）をご利用ください。AI が回答し、緊急なら人間が対応します。

**Q: 返答が遅い場合は？**
A: 込み具合により、最大 48 時間かかる場合があります。催促は不要です。

**Q: 仲介業者に相談してからのほうがいい？**
A: 仲介業者に関する問題なら、仲介業者に先に相談してください。その後、Ancu365 に問い合わせ。

**Q: 過去のやり取りを見たい場合は？**
A: アプリの「問い合わせ」タブから、過去のチケットを見ることができます。

## セキュリティに関する問い合わせ

セキュリティ問題や個人情報漏洩の報告は：
- **メール:** security@ancu365.jp
- **電話:** 緊急の場合のみ、support の番号に「セキュリティ緊急」と伝える

ご遠慮なくお問い合わせください。あなたのご質問は、私たちの改善につながります。
