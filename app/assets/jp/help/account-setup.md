# アカウント設定

Ancu365 のアカウント設定方法について説明します。

## 初回セットアップ

### ステップ 1: サインアップ
1. Ancu365 アプリを開く
2. 「アカウントを作成」をタップ
3. メールアドレスを入力
4. 確認メールが届きます

### ステップ 2: メール確認
1. 届いたメール内のリンクをクリック
2. パスワードを設定
   - 8 文字以上
   - 大文字、小文字、数字を含める
3. 「アカウント作成」を完了

### ステップ 3: プロフィール入力
1. 氏名、電話番号、住所を入力
2. 身分証のアップロード（仲介業者の指示に従う）
3. 「完了」をタップ

### ステップ 4: 認証コード設定
1. 2 段階認証（2FA）を設定
   - メールまたは SMS で認証コードを受け取る
   - よりセキュアなログインが可能

## 後でできる設定変更

### 基本情報の変更
1. 「アカウント設定」を開く
2. 「基本情報」をタップ
3. 氏名、電話番号、住所などを編集
4. 「保存」をタップ

### パスワード変更
1. 「アカウント設定」から「セキュリティ」を選択
2. 「パスワード変更」をタップ
3. 現在のパスワードを入力
4. 新しいパスワードを 2 回入力
5. 「変更する」をタップ

### メールアドレス変更
1. 「アカウント設定」から「メールアドレス変更」を選択
2. 新しいメールアドレスを入力
3. 確認メールが届きます
4. メール内のリンクをクリックして確認

### 電話番号変更
1. 「アカウント設定」から「基本情報」を選択
2. 電話番号を編集
3. SMS で確認コードが届く
4. コードを入力して確認

## セキュリティ設定

### 2 段階認証（2FA）の設定
1. 「アカウント設定」から「セキュリティ」を選択
2. 「2 段階認証を有効にする」をタップ
3. メールまたは SMS を選択
4. 確認コードを入力
5. 「有効にする」をタップ

**メリット:** パスワードだけでなく、確認コードでもログインが必要。より安全です。

### ログイン通知
1. 「セキュリティ」から「ログイン通知」を有効に
2. 新しいデバイスからログインしたとき、通知が届きます
3. 不正ログインを早期に発見できます

## よくある質問

**Q: パスワードを忘れました。どうすればいいですか？**
A: ログイン画面の「パスワードを忘れた」をタップ。メールが届き、リセットできます。

**Q: 複数のデバイスからログインできますか？**
A: はい。同時ログインは 3 台までです。

**Q: アカウント情報は変更後、いつ反映されますか？**
A: ほとんどの場合、数秒以内に反映されます。メールアドレス変更は確認後に反映。

**Q: セキュリティ設定が難しいです。**
A: 「問い合わせ」から相談できます。担当者がサポートします。

ご不明な点は、「問い合わせ」セクションからお聞きしています。
