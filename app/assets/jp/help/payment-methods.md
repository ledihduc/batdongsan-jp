# 支払い方法

Ancu365 での支払いに対応している方法を説明します。

## 支払いの種類

### 1. 更新料・敷金精算などの料金
- 仲介業者を通じての支払い
- Ancu365 では集金していません

### 2. 保証料・火災保険料
- 指定の保証会社や保険会社に支払い
- 支払い方法は各会社の指示に従ってください

## よく使われる支払い方法

| 方法 | 対応状況 | 説明 |
|---|---|---|
| 銀行振込 | ✅ | 指定の口座に振込（手数料は仲介業者が負担する場合が多い） |
| クレジットカード | △ 場合による | 仲介業者が対応していれば利用可 |
| 口座自動振替 | ✅ | 指定口座から自動引き落とし（契約者負担の手数料あり） |
| コンビニ支払い | △ 場合による | 一部の仲介業者が対応 |
| 現金 | ✅ | 店舗訪問時に支払い（仲介業者に確認） |

## 支払い期限

- **更新料** → 更新月の末日までが一般的
- **敷金精算** → 精算確定から 1～2 ヶ月以内
- **保証料** → 契約時または更新時（保証会社の指定日）

Ancu365 に「支払い期限」が表示されるので、確認しましょう。

## 支払いが遅れた場合

- 遅延金が発生する場合があります
- 仲介業者に直ちに連絡してください
- 支払い期限を過ぎそうな場合は、早めに相談しましょう

## よくある質問

**Q: どの支払い方法が一番安全ですか？**
A: 銀行振込またはクレジットカード（保証企業経由）が安全です。現金や個人間の送金は避けましょう。

**Q: 支払い方法は変更できますか？**
A: 仲介業者に相談してください。契約条件に記載がある場合があります。

**Q: 手数料は誰が負担しますか？**
A: 仲介業者または大家さんが負担するのが一般的です。Ancu365 の内訳で確認できます。

Ancu365 での支払い問題については、「問い合わせ」からお聞きしています。
