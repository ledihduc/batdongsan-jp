# データをダウンロードする（データ請求）

あなたが Ancu365 に登録した全ての個人情報を、ダウンロードすることができます。（法律では「データ請求」と呼びます）

## なぜ必要？

- **別のサービスに乗り換えたい** → 自分のデータを持ち出したい
- **情報を確認したい** → どんなデータが保管されているか見たい
- **バックアップを取りたい** → 自分で保存しておきたい

## ダウンロード手順

### ステップ 1: アプリを開く
- ホーム画面から「アカウント設定」をタップ

### ステップ 2: 「個人情報のエクスポート」を選択
- 「プライバシー」セクションから「個人情報のエクスポート」をタップ

### ステップ 3: 本人確認
- メールアドレスとパスワードを入力して確認
- （セキュリティのため、再度確認します）

### ステップ 4: リクエスト送信
- 「ダウンロード開始」ボタンをタップ
- 「リクエストを受け付けました」というメッセージが表示されます

### ステップ 5: メールを確認
- 登録したメールアドレスに、メールが届きます
- メール内のリンクをクリック
- ファイルが自動的にダウンロードされます

## ダウンロード時間

- **通常** → 数分以内にメール到着
- **最長** → 数時間かかる場合があります
- メール内のリンクは **30 日間** 有効です

## ダウンロードされるもの

### PDF 形式（読みやすい）
- あなたの個人情報の要約
- 保存されているファイルのリスト
- ブラウザやスマートフォンで簡単に見られます

### CSV 形式（エクセルで開ける）
- 詳細な情報
- エクセルなどのアプリで加工・分析できます

### 含まれるデータ

- **基本情報** → 名前、電話番号、メールアドレス、住所
- **書類** → アップロードした身分証やファイル
- **取引履歴** → 応募、更新手続き、敷金精算などの記録
- **アクティビティ** → いつログインしたか、などの操作記録

### 含まれない可能性がある

- **部分的に匿名化されたデータ** → 統計情報など
- **セキュリティログ** → 技術的なアクセス記録

## よくある質問

**Q: ダウンロード後、どうやって見るのですか？**
A: PDF ファイルはどのスマートフォンでも開けます。CSV ファイルは Excel などのアプリで開けます。

**Q: ファイルは本当に安全ですか？**
A: メール内のダウンロードリンクは暗号化されています。ただし、メール自体は暗号化されていないため、リンク到着から 30 日以内に、なるべく早くダウンロードしてください。

**Q: 何度もダウンロードできますか？**
A: はい。何度でもリクエストできます。1 回のリクエストで複数回ダウンロード可能です（30 日間有効）。

**Q: ダウンロード時間が長いのは何故ですか？**
A: システム負荷が高い場合、数時間かかることがあります。それでも 24 時間以内には到着します。

## 問題が発生した場合

- **メールが届かない**
  → スパムフォルダを確認。それでもない場合は「問い合わせ」から報告

- **ファイルが開けない**
  → ファイルが破損している可能性。「問い合わせ」から再度リクエストしてください

- **情報が間違っている**
  → 「アカウント設定」から修正、または「問い合わせ」から報告

ご不明な点は、「問い合わせ」セクションからお聞きしています。
