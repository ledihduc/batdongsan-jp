# JP Help Center Articles

This directory contains the 14 FAQ articles for the Japan market help center.
Files are bundled with the app for offline-first reading.

Content is managed by the ops team. Do not edit article markdown directly in code review —
submit content changes via the ops workflow.

## Article Structure

Each `.md` file corresponds to one `HelpArticle` in `help_models.dart`.
File naming: `{id}-{slug}.md` — the `id` prefix matches `HelpArticle.id`.

## Categories

1. 更新 (Renewal) — articles 01–03
2. 敷金精算 (Deposit Settlement) — articles 04–06
3. APPI/プライバシー (Privacy) — articles 07–09
4. 支払い (Payment) — articles 10–11
5. アカウント (Account) — articles 12–13
6. 問い合わせ (Support) — article 14
