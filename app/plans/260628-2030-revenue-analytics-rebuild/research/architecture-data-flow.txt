COMPUTATION PIPELINE
====================

User selects: Month = 2026-06, Period = month
                   ↓
         [PeriodSelector]
                   ↓
   ReportProvider.fetchRevenue(period='month', date='2026-06')
                   ↓
   ApiReportRepository.fetchRevenue()
                   ↓
   HTTP GET /api/host/reports/revenue?period=month&date=2026-06
                   ↓
   [Backend calculates]
   • SELECT invoice_line_items WHERE period_start/end IN [2026-06]
   • Group by category (rent, electricity, water, service, ...)
   • Sum amounts by category and building
                   ↓
   Response: RevenueReportModel
   { period: 'month', date: '2026-06', total: 50000000,
     breakdown: { rent: 40M, electricity: 5M, water: 3M, service: 2M },
     byBuilding: [{ buildingId: 1, name: 'Building A', total: 30M }, ...] }
                   ↓
   [Client renders]
   • RevenueBreakdownTable displays:
     - "Tổng doanh thu: 50.000.000 VND" (hero)
     - Category breakdown (sorted by amount)
     - By-building breakdown
     - CSV export button
                   ↓
   CSV download:
   ReportProvider.downloadInvoicesCsv(month='2026-06')
                   ↓
   HTTP GET /api/host/reports/export?type=invoices&month=2026-06
                   ↓
   [Backend generates]
   CSV: header row + one row per invoice line item
   Response: Raw bytes (UTF-8, Content-Type: text/csv)
                   ↓
   [Client saves + shares]
   File saved: /tmp/invoices-2026-06.csv
   Share via Share.shareXFiles() → native intent (email, Zalo, etc.)
